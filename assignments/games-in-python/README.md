
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a playable Hangman game that uses Python strings, loops, conditionals, user input, and random selection. Players will guess letters to reveal a hidden word before they run out of attempts.

## 📝 Tasks

### 🛠️ Task 1: Build the Guessing Game

#### Description
Create the core game loop. Select a word at random from a predefined list, accept letter guesses, and show the letters the player has revealed.

#### Requirements
Completed program should:

- Randomly select one word from a predefined list at the start of each game.
- Display each hidden letter as an underscore and reveal matching letters after a correct guess.
- Keep track of guessed letters so the player can see their progress.
- Decrease the number of remaining attempts after an incorrect guess.

### 🛠️ Task 2: Complete the Game Flow

#### Description
Finish the game by handling its end conditions and giving the player clear feedback about the result.

#### Requirements
Completed program should:

- End the game when the player reveals every letter in the word or runs out of attempts.
- Display a win message when the player guesses the word.
- Display a lose message and reveal the word when the player runs out of attempts.
